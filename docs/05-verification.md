# 검증 증거와 남은 범위

[← 포트폴리오](../README.md) · [현재 상태](08-current-state.md)

**기준일: 2026-10-12.** 비공개 소스·설계·작업 보고를 읽어 설명을 정리했습니다. 테스트 작성·정적 검토는 실행 성공의 증거가 아닙니다. 공개본에는 테스트 구현·원시 로그를 배포하지 않습니다.

## 상태 표현

| 표현 | 의미 |
|---|---|
| 설계 승인 | 규칙·책임 확정. 구현 완료와 별개 |
| 코드 구현 | 현재 소스에 경로 존재. 미커밋 여부·실행 대기를 함께 표시 |
| 범위 검증 | 특정 버전·시나리오의 빌드·시험·실행 근거 존재 |
| 미검증·후속 | 콘텐츠 연결·다인·제품맵·패키지·성능 등 남은 범위 |

이번 문서 작업에서는 소스의 소유권·거래·수치·이벤트 경계를 승인 설계와 대조하고 내부 링크·공개 파일 범위를 확인합니다. Unreal 빌드·PIE·자동화·패키지·성능 측정은 새로 하지 않았습니다. Mermaid는 설명용 그림입니다.

## 기존 실행 기록의 제한된 결과

각 작업 시점의 기록이며 이후 미커밋 변경까지 인증하지 않습니다.

| 기록 | 확인된 결과 | 해석의 한계 |
|---|---|---|
| 10월 11일 XP 제거·전리품 기본 전환 | 빌드 3종, 전체 자동화 772 중 770 성공, 제품 드롭 풀 2인 지급 시험 3/3, cook 오류 0 기록 | 기존 실패 2건 존재. 이후 공용 Coin·성장 변경 검증이 아님 |
| 초기 성장·CI 보강 | 강화 14·성장 수식 3·탄창 13, 피해 스냅샷 5/5 및 기존 회복·흡혈·네트워크 Pickup 표적 시험 성공 기록 | 최신 전체 축·실제 7무기 소비·후속 경제 통합 완료가 아님 |
| 스폰 시간 구간 | SpawnWindow PASS, SpawnPacing 6/6 등 성공, 초 단위 표시 수정 후 빌드·표적 시험 기록 | 실제 맵 적용·코어 조건·2인 PIE·비유니티 검증과 별개 |
| 로비·UI 부분 실행 | 실제 2인 로비→런, 준비 확정·취소, 설정 복귀, 사격·장전, Downed·관전·근접 부활 기록 | 4인·추가 화면비·전체 HUD·패키지 렌더링 미검증 |
| 무기 외형 저작 | BP 컴파일, 지정 패키지 저장·재로드, 수치 보호 비교와 일부 사용자 형상 확인 | ADS·손 접촉·장전 취소·다인 TP·최종 GPU 색 전체 통과가 아님 |

전체 자동화의 기존 실패는 Water 순서 의존과 퇴역한 표현 검증 BP 관련 사례로 기록되었습니다. 일부 빌드에는 시험 이전 엔진 초기화 오류도 별도 기록되어 있어 성공 수만으로 로그 전체 무오류를 주장하지 않습니다.

공용 처치 Coin·WSU 거래·성장 상태 운반과 추가 소비부·Stock 순수 수학·Power 수학 지원·일부 CI/차폐 지원은 최신 코드·정적 근거와 실행을 구분합니다. 최신 보고가 실행하지 않았다고 적은 변경은 실행 대기로 남깁니다.

## 성능을 주장하려면

적 1000+는 스트레스 목표입니다. 측정에는 소스 버전, 엔진·하드웨어, 해상도·빌드 설정, 활성 적 수, 인원, 호스트·클라이언트 구분, 측정 시간과 프레임·네트워크 지표가 필요합니다. 공개 가능한 원시 자료가 없는 개선율·FPS 그래프는 넣지 않았습니다.
