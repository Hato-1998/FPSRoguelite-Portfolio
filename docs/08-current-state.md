# 현재 설계·구현 인벤토리

[← 포트폴리오](../README.md) · [검증 근거](05-verification.md)

**2026-10-23 공개 데모 기준.** 게임 이름은 **ART: Arcade Reclamation Team**(개발 코드명 FPSRoguelite)입니다. 공개 데모의 범위는 1~4인 협동, 런 시작, 전투·파밍·무기 성장, 20:00 최종 보스, 승리·패배, 결산입니다. 표의 "구현 상태"는 비공개 저장소의 커밋과 작업 기록에서 확인한 내용이며, 실행으로 확인한 범위는 [검증 근거](05-verification.md)에 따로 적었습니다. 설계 승인, 코드 구현, 실행 검증은 같은 상태가 아닙니다.

## Combat Item 12종

처치 회복, 명중 탄창 회복, 처치 폭발, 최대 HP, 최대 Shield, 흡혈, 이동 속도, Double Jump, 연쇄 번개, 화상, 명중 Slow, 재장전 후 이동 증가입니다. 12종의 DataAsset 저작과 처치 드랍 풀 연결은 확인했습니다. 12종 각각의 실제 플레이 검증은 이 문서가 보증하지 않습니다.

## 제거된 것

데모 범위를 줄이고 "처치하면 떨어지고 강해진다"는 흐름을 짧게 만들기 위해 아래를 제거했습니다(DL-180).

- 코인 지갑·지급·표시 UI와 시작 코인, 리롤 충전. 로비의 연습용 코인만 남겼습니다.
- 무기·스톡·품질 자판기와 품질 도박. 품질은 공급 출처별 분포로 정합니다.
- 상점, Perk 구매기, Recycler(분해·환급)와 RECYCLE 미션.
- 기존 미션 8종과 미션 구슬. 비행 표적 1종으로 대체했습니다.
- XP 구슬·파티 레벨과 화면형 카드 3택1·리롤 상점(10-11 이전 결정).
- Perk 선택 창. 5레벨마다 자동 장착으로 바꿨습니다(DL-178).

제거 작업은 공급, 결합 분리, 미션, 콘텐츠 순으로 진행했고, 콘텐츠와 미션은 커밋되었습니다. 데모 맵과 콘텐츠에서는 소비처가 모두 빠졌으며, 남은 내부 코드(거래 RPC·상점 컴포넌트·Recycler) 정리는 확정된 제거 명세에 따른 후속 단계입니다. 내부에 남은 Card·Enhancement 타입명은 이력과 기존 기반 재사용을 반영하며, 화면형 카드 개념은 폐기되었습니다.
