## 최신 Combat Item 12종

처치 회복, 명중 탄창 회복, 처치 폭발, 최대 HP, 최대 Shield, 흡혈, 이동 속도, Double Jump, 연쇄 번개, 화상, 명중 Slow, 재장전 후 이동 증가입니다. 각 아이템의 기본 최대 스택은 3이며 Double Jump는 1입니다. 전체 목록의 승인과 모든 DataAsset·효과 연결·실제 플레이 검증은 구분합니다.

화면형 카드 3택1·리롤 상점, XP 구슬·파티 XP·파티 레벨·레벨업 Coin, 별도 Power 강화 머신은 현재 성장 규칙에 포함하지 않습니다. 내부에 남은 Card·Enhancement 타입명은 이력과 기존 기반 재사용을 반영합니다.

현재 공개 저장소는 실행 가능한 배포본이 아닙니다. 설계 목표와 구현 경계를 독자가 비교할 수 있도록 정리한 프로그래밍 포트폴리오입니다.
